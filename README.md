# Projet-en-C-Calcul-Matriciel
Application développée en langage C pour la gestion et la manipulation de matrices creuses, à travers une interface en ligne de commande. Le programme permet la création d’une matrice identité, l’addition de matrices creuses et la conversion d’une matrice dense en matrice creuse. Conçu dans un cadre pédagogique et académique.
